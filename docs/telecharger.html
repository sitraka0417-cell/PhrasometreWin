Phrasomètre

Compteur de phrases mensuelles pour Windows, synchronisé avec votre compte Google.

⬇ Télécharger pour Windows
Windows 10 et 11 (64 bits)

Installation

  1. Téléchargez puis lancez Phrasometre-Setup.exe.
  2. Suivez l'assistant (choix du dossier, raccourcis).
  3. Ouvrez Phrasomètre et, si vous le souhaitez, connectez-vous avec Google pour synchroniser vos données.

Mise à jour

  1. Relancez simplement le nouvel installateur : vos phrases et vos réglages sont conservés.
Message de Windows ? Si « Windows a protégé votre ordinateur » apparaît, cliquez sur Informations complémentaires, puis Exécuter quand même. L'application n'est pas encore signée numériquement.
